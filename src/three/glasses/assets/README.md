# Continent artwork

Derived from Natural Earth geography region polygons (public domain):
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_geography_regions_polys.geojson
https://www.naturalearthdata.com/about/terms-of-use/

Downloaded 2026-10-02. Orthographic projections centred on each continent were simplified and fitted to a shared label mask. Oceania is represented by Australia and New Zealand; very small Pacific islands are omitted at this icon scale. The white map and lettering on black are data for the gold material alpha mask, not visible background colours. No runtime network requests to Natural Earth are required.

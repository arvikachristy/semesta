# Let's begin

An experimental personal portfolio exploring graphical interfaces, creative frontend engineering and interactive systems.

## Stack

- Next.js
- React
- TypeScript
- Three.js
- React Three Fiber
- Drei
- GSAP
- D3

## Philosophy

Semesta is intentionally starting as an empty technical shell.

The visual system and interaction model will be developed through experiments rather than predetermined by a component library.

## Development

```sh
npm install
npm run dev
```

## Learning roadmap

1. Three.js fundamentals

3. Camera and world movement
4. React Three Fiber
5. Animation and transitions
6. Custom shaders
